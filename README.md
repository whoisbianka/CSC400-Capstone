# CSC400 Capstone — Python-first Flask demo

College and major exploration with server-rendered chat, questionnaire, catalog, and program details. Launch through `app.py`; Python uses Flask and WTForms, with HTML retained as server-rendered templates. Uses 15 fictional demo programs; no PostgreSQL setup required.

See [setup and architecture](PYTHON-DEMO.md) for installation, local launch, tests, session limitations, and the future PostgreSQL integration boundary.

Database integration is prepared for local PostgreSQL and Google Cloud SQL. See [connection setup](DATABASE-CONNECTION.md); demo mode remains the default.
